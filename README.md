# 🎨 Random Background Color Generator

مشروع بسيط باستخدام JavaScript يقوم بتغيير لون خلفية الصفحة بشكل عشوائي عند الضغط على زر.

هذا المشروع يساعدك على فهم كيفية إنشاء قيم عشوائية والتعامل مع الأحداث في JavaScript.

---

## 🚀 فكرة المشروع

الصفحة تحتوي على:

- عنوان
- زر
- عند الضغط على الزر يتم تغيير لون الخلفية إلى لون عشوائي

---

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript

---

## 🎯 ماذا تعلمت من المشروع؟

- استخدام `Math.random()` لإنشاء أرقام عشوائية
- إنشاء لون عشوائي باستخدام Hex Color
- استخدام `Math.floor()`
- تحويل الرقم إلى نص باستخدام `toString(16)`
- التعامل مع حدث الضغط `onclick`
- تغيير خصائص CSS باستخدام JavaScript
